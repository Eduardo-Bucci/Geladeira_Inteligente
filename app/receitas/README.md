# Geladeira Viva — Página de Receitas

Tela de receitas para Next.js App Router, usando TypeScript, Tailwind CSS e lucide-react.

## O que já funciona
- Busca por nome de receita ou ingrediente.
- Filtros por categoria.
- Filtro de receitas com todos os ingredientes disponíveis.
- Cards com tempo, dificuldade e ingredientes disponíveis/faltantes.
- Modal com ingredientes e modo de preparo.
- Favoritos e marcação local de receita preparada.

## Observações
- Os dados são exemplos fixos no frontend; favoritos e estado de preparação ficam apenas na memória da página.
- As imagens usam URLs externas do Unsplash, então precisam de conexão com a internet.
- Ainda não existe integração com a API Express nem atualização do estoque MySQL.
